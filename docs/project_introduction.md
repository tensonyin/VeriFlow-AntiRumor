# 🛡️ 作品简介：《谣言终结者 (VeriFlow-AntiRumor)》
**—— 基于多源异构对抗博弈的多模态事实核查与适老化辟谣系统**

本项目专为**第九届全国青少年人工智能创新挑战赛 - “AI智能体设计开发专项赛”**决赛路演研发。系统致力于解决 AIGC 时代网络谣言泛滥、大模型“事实幻觉”与老年群体“数字鸿沟”等痛点，是一套软硬一体、多端协同的智能事实核查与适老化辟谣平台。

---

## 一、 作品主要功能

1. **多模态便捷求助**：支持纯文本、语音输入及微信聊天/朋友圈截图（自动 OCR 提取）一键求助。
2. **“普通模式”（科技白盒版）**：面向大众，以 SSE 流式展示 AI “思维风暴”日志（检索与博弈细节），并生成手势可缩放拖拽的 **Mermaid 逻辑推理拓扑图**与 Markdown 事实分析报告。
3. **“长辈模式”（温暖大字版）**：面向银发族，大字号高对比度视觉。以打字机和盖章音效缓解等待焦虑；结论呈现为**拟物化带红章辟谣小票**与**三段式大字报海报**，支持温情儿女声 **TTS 语音播报**与一键导出朋友圈长图分享。
4. **行空板 (Unihiker) 物理终端**：长辈将硬件摆放于家中，按 A 键一键录音求助，自动触发云端多智能体核查，并由音箱播报安心报告，实现零学习门槛。

---

## 二、 核心技术特点

1. **23节点红蓝博弈工作流**：在 Dify 构建级联管线，由“正方事实取证”跨境检索与“反方逻辑审计”挑刺漏洞进行红蓝对抗，最终由“真相裁决官”执行多源交叉审计定性。
2. **沙箱自愈防死链幻觉**：工作流级联 Python 代码沙箱，自动并发测试并剔除失效出证链接（404），保证参考源真实可用，彻底消除大模型虚构死链的幻觉。
3. **Canvas CORS 跨域代理**：Express 后端架设同源代理，解决 html2canvas 截图时跨域图片污染画布导致的保存失败问题，实现朋友圈卡片秒级生成。
4. **d3-zoom 拓扑图交互**：引入 d3-zoom 拖拽捏合手势，动态注入 CSS 优化间距，解决大字号下 Mermaid 流程图字体重叠和边界遮挡难题。
5. **硬件级优化与代理播报**：Python 硬件端自动洗涤 Emoji 字符防止板载 Linux Tkinter 崩溃；采用“远程 Web 虚拟扬声器”代理，解决板载硬件功率短板。

---

## 三、 作品主要创新点

1. **红蓝多 Agent 对抗事实核查**：改变了传统单点检索机制，通过红蓝对抗模拟“法庭辩论”，极大地提升了结论的客观性与逻辑深度。
2. **沙箱实时测试死链自愈**：首创在智能体管线中集成运行期代码沙箱自检外链，抹除幻觉，打造高可信度的“实证链条”。
3. **人本温度的深度适老化交互**：将复杂的推理白盒包装为符合长辈直觉的“实体账单小票+养生大字报+语音朗读”，跨越数字鸿沟。
4. **软硬联动与物理化触角**：通过行空板端云协同，将 AI 核查能力延伸至实体家居空间，实现无障碍物理化交互。
